# Wordlist de parametros (query, body, headers, cookies) para param-mining.
# Tamano ~700 entradas. Hits reales en CryptoVulnX:
#   debug, include, fields, as_user_id, bypass_rate_limit, role, search,
#   skip_validation, fee_override, rate_override, bypass_kyc, custom_rate,
#   ?token (en backup.php), ?key (en export.php), ?file (en logs.php),
#   ?cmd (en exec.php), ?action (en debug.php)
# Headers: X-Debug-Token, X-Forwarded-For, X-Original-URL, X-Real-IP,
#   X-Api-Version, X-Service-Token, X-Admin-Token, X-Bypass-RateLimit
# Cookies: debug_mode, internal_user, feature_flags
# El resto es ruido para que arjun/x8/ffuf muestren su comportamiento normal.
